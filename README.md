# Planner

یک برنامه شخصی و ساده برای برنامه‌ریزی روزانه و پیگیری تعهدات.

Planner با تمرکز روی تجربه‌ای ساده و دلنشین طراحی شده تا بتوانید برنامه‌های خود را ایجاد کنید، کارهای روزانه را دنبال کنید و میزان پیشرفت خود را ببینید.

## Today

صفحه اصلی Planner با تمرکز روی فعالیت‌های امروز طراحی شده است؛
تعهدات امروز، میزان پیشرفت و روزهای برنامه را در یک نمای ساده و فارسی نمایش می‌دهد.
